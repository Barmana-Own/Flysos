روش پیشنهادی اتصال پروازها: PUSH روی HTTPS/443
================================================

چرا؟
هاست cPanel به 109.122.250.170:3000 اتصال خروجی ندارد. در این روش، خود سرور پرواز
که به API محلی دسترسی دارد، داده را به https://flysos.ir روی پورت 443 ارسال می‌کند.
بنابراین محدودیت outbound هاست کاملاً دور زده می‌شود.

1) در فایل .env بک‌اند FlySOS یک کلید بلند قرار دهید:
FLIGHT_IMPORT_SECRET=یک-رشته-تصادفی-حداقل-۴۸-کاراکتری
FLIGHT_CACHE_ENABLED=false

2) بک‌اند FlySOS را Restart کنید.

3) فایل scripts/pushFlightsToFlySOS.mjs را روی سرور پرواز کپی کنید.

4) روی سرور پرواز متغیرها را تنظیم و یک بار تست کنید:
export SOURCE_FLIGHTS_BASE_URL="http://127.0.0.1:3000/api/flights"
export SOURCE_FLIGHTS_USERNAME="نام کاربری سرویس"
export SOURCE_FLIGHTS_PASSWORD="رمز سرویس"
export FLYSOS_IMPORT_URL="https://flysos.ir/api/flights/import"
export FLIGHT_IMPORT_SECRET="همان کلید مرحله 1"
node /path/to/pushFlightsToFlySOS.mjs

5) اگر پیام import successful دیدید، Cron هر 5 دقیقه اضافه کنید:
*/5 * * * * /usr/bin/env SOURCE_FLIGHTS_BASE_URL="http://127.0.0.1:3000/api/flights" SOURCE_FLIGHTS_USERNAME="..." SOURCE_FLIGHTS_PASSWORD="..." FLYSOS_IMPORT_URL="https://flysos.ir/api/flights/import" FLIGHT_IMPORT_SECRET="..." /usr/bin/node /path/to/pushFlightsToFlySOS.mjs >> /var/log/flysos-flight-push.log 2>&1

تست روی هاست FlySOS:
curl -sS https://flysos.ir/api/flights/status?limit=3

روش جایگزین دوم: Reverse proxy روی HTTPS
---------------------------------------
اگر به تنظیمات Nginx سرور 109.122.250.170 دسترسی دارید، API پورت 3000 را پشت یک دامنه
HTTPS روی پورت 443 قرار دهید و در .env هاست FlySOS این مقدار را تنظیم کنید:
EXTERNAL_FLIGHTS_RELAY_URL=https://flights-api.example.com/api/flights
سپس FLIGHT_CACHE_ENABLED=true و Restart.
