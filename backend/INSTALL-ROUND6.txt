نصب بک‌اند Round 6
==================

1) فایل ZIP را در /home/flysosir آپلود کنید.
2) در Terminal:

source /home/flysosir/nodevenv/public_html/backend/22/bin/activate
cp /home/flysosir/public_html/backend/.env /home/flysosir/backend.env.backup
cd /home/flysosir/public_html/backend
unzip -o /home/flysosir/flysos-backend-2026-07-20-round6-stability-api-push.zip
cp /home/flysosir/backend.env.backup .env
npm install --omit=dev
npm run db:cms
mkdir -p tmp uploads
touch tmp/restart.txt

سپس در cPanel > Setup Node.js App روی Restart کلیک کنید.

خروجی migration باید شامل این پیام باشد:
Round 6 stability, FAQ/support and permissions migration completed successfully.

تست‌ها:
curl -sS https://flysos.ir/api/health
curl -sS https://flysos.ir/api/faqs
curl -sS https://flysos.ir/api/articles
curl -sS 'https://flysos.ir/api/flights/status?limit=3'

برای راه جایگزین API پرواز، فایل PUSH-FLIGHTS-SETUP.txt را بخوانید.
